# Contributions and Attribution

## Personal Contribution

Carringtone Kinyanjui designed and implemented the matched-checkpoint
activation-geometry study, including the extraction, geometry, trajectory, and
causal-evaluation pipeline. He specified the decision rules, ran the OLMo 2
experiments, conducted the robustness and precision analyses, interpreted the
supported and unsupported hypotheses, and wrote the reports in this release.

This statement applies to the repository implementation and reports unless a
file states otherwise.

## External Research Artifacts

The OLMo 2 models are external research artifacts developed by Ai2. This
repository references pinned model revisions but does not redistribute model
weights. The model cards, papers, licenses, and responsible-use guidance remain
authoritative for those artifacts.

## Software Dependencies

The project relies on PyTorch, Transformers, Hugging Face Hub, NumPy, SciPy,
scikit-learn, PyYAML, Matplotlib, and related transitive dependencies. Those
projects retain their own copyrights and licenses.

## Prompt Data

The prompt sets in `data/` are generated by this repository's deterministic
prompt builder. They are synthetic evaluation prompts rather than collected
user data.
